# 拟境 · nijing

> 世界书驱动的沉浸式情境推演引擎

把自己放进一个世界，做一个行动，看这个世界如何回应。

不是数值游戏 —— 没有血条、金币和属性面板。全屏是长篇小说的阅读质感，
每一幕由你自己配置的大模型实时生成，结尾给出几个可选行动，也可以直接写下你自己的。

**应用本身不内置任何剧本。** 你演谁、身处什么时代、用什么文风，全部由你写的「世界书」决定。
历史正剧、架空江湖、近未来都市 —— 同一套引擎，换一本书就是另一个世界。

## 核心特性

| 特性 | 说明 |
|---|---|
| **沉浸阅读与零 HUD** | 进入推演后隐藏系统栏，屏幕上只剩文字；单击屏幕唤出/收起顶栏，3 秒无操作自动淡出；支持阅读防熄屏 |
| **原生双轨流隔离** | 网络层按协议原生分离 `reasoning_content` / `reasoning` / `thought` 与 `content`，配合零回溯流式分流器兼容内嵌 `<think>` 反代，从根源杜绝思考草稿泄漏至正文 |
| **多接口开箱即用与 400 自愈** | 原生支持阿里云百炼（含业务空间 ID 加速）、DeepSeek 官方及任意 OpenAI 兼容中转 / 本地免 Key 接口；遇到思考扩展参数或 `max_tokens` 不兼容时自动降级重试，并直透真实服务端错误 |
| **深度思考与预算控制** | 自由开关 Thinking 模式并配置思考预算（自由不限 / 1k / 2k / 4k / 8k）；推演期间思考面板常驻可随时展开收起，完结后归档至章节菜单 |
| **高性能虚拟化阅读器** | `CustomScrollView` + `SliverList.builder` 懒加载历史幕次，流式区通过独立 `ListenableBuilder` 与 60ms 节流局部刷新（历史章节零重绘），流式与落定排版像素级一致 |
| **视口停泊保护** | 长文本流式涌入时，向上翻阅前文立即暂停自动跟随，右下角浮现「↓ 有新内容流出」悬浮胶囊，一键平滑回底，手势互不抢夺 |
| **后台推演与断流容灾** | `GenerationController` 独立托管生命周期，退回首页不中断推演、完成后自动落盘；网络波动自动重连重试，重试耗尽且正文充足时自动残文抢救，绝不写入虚假降级污染存档 |
| **非阻塞增量编年史** | 每 5 幕在后台静默增量压缩最近幕次（强制禁思考并剥离思维链），零等待不卡 UI，长局记忆清晰连贯 |
| **世界状态与世界观察** | 每幕维护结构化「此刻状态」（时间 / 地点 / 已知事实 / 人物关系 / 进行中事件）；默认收起，点开即览全局局势 |
| **世界线时空分岔树** | 从任意历史幕分岔出全新世界线重新抉择，原世界线完整保留、随时一键切换、重命名或删除，各线状态天然隔离 |
| **主宰模式** | 全局或自由输入框单次开启最高权限（金色高亮），将玩家意志作为不可撼动的既成事实写入剧情与世界状态，严禁强行反转 |
| **世界书与 AI 快速创建** | 支持完整字段手动编写、JSON / 纯文本导入导出，或一句话由 AI 扩写成完整世界书（透出真实报错，先预览编辑再保存） |
| **分槽独立文件原子存档** | 每局推演独立保存为 `slot_<id>.json`（`.tmp` 原子替换防损坏），单档异常不连坐其他存档，自动无缝迁移旧版存档 |
| **物理文件导出与原生分享** | 推演故事（`.md` / `.txt`）、世界书、存档与运行日志均支持导出至 `Download/nijing/` 并通过 Android FileProvider 原生分享 |
| **四套护眼阅读皮肤** | 拟境（默认，冷调深墨）/ 时代报章 / 暗夜墨石 / 素雅宣纸，支持字号、行距、段首缩进与段间距微调 |
| **一切只在本机** | 世界书、存档与 API Key 全留本地；Key 走系统加密存储，运行日志默认关闭且具备双重精准脱敏 |

## 主题与排版

四套皮肤均走「低饱和、无题材暗示」路线 —— 换一本书不用换皮肤：

| 名称 | 定位 |
|---|---|
| **拟境**（默认） | 冷调深墨 + 雾蓝强调色，长时间沉浸阅读不累眼 |
| **时代报章** | 暖纸 + 砖红，旧报纸档案质感 |
| **暗夜墨石** | 暖黑 + 橘调，夜间护眼 |
| **素雅宣纸** | 亮白纸面，典雅白描 |

阅读页使用专用色板 `ReadingPalette`（页面底色 / 正文墨色 / 极淡分隔线 / 幕首标记色 / 选项卡底色），并在「我的 → 阅读设置」中提供字号、行距、段首缩进（顶格 / 一格 / 两格）、段间距（紧凑 / 适中 / 宽松）、打开跳至最新一幕、顶栏自动隐藏与防熄屏开关。

## 快速开始

1. 装好 App，首次打开会引导配置模型接口
2. 进入「我的 → 模型设置」，选择服务商并填入 API Key（本地 `localhost` / 局域网自定义接口可留空），点击「测试连接」
   - **阿里云百炼**：默认 `qwen-plus`，快捷支持 `qwen-max` / `qwen-turbo` / `qwen3-235b-a22b` / `qwen3-32b` / `qwq-plus`，可选填华北 2 业务空间 ID
   - **DeepSeek 官方**：支持 `deepseek-chat` 与原生推理模型 `deepseek-reasoner`
   - **自定义 OpenAI 兼容**：填完整 Base URL（如 `https://api.example.com/v1`），兼容各类中转站、OpenRouter、Gemini / Claude / GPT 代理及本地 Ollama / vLLM
3. 「**世界**」标签 → 「创建世界」（AI 快速创建 / 手动编写）或「导入」
4. 「**继续**」标签 → 「开始一段新的推演」→ 选择世界 → 进入

底部三个入口：**世界**（我创造什么）· **继续**（我正在经历什么）· **我的**（设置与数据管理）。

## 世界状态 vs 编年史

这两块都会进入 system prompt，但职责严格区分，互不打架：

| | 世界状态（`WorldState`） | 编年史（`Chronicle`） |
|---|---|---|
| 体裁 | 结构化条目 | 精炼散文摘要 |
| 回答 | 此刻是什么状态 | 过去发生过什么 |
| 时态 | 只写当下 | 只用过去时 |
| 维护方式 | 每幕 `<state>` 合并校验截断（事实 ≤12 / 关系 ≤12 / 事件 ≤8） | 每 5 幕后台静默增量压缩最近幕次（强制禁思考） |

判定规则：回退到第 5 幕后不再成立的信息归**世界状态**；已经发生且永远成立的大事归**编年史**。

## 世界线与「一本书一局」

- **一本书一局**：进入已有进度的世界书会自动接着玩；想从头体验可在长按菜单选择「重新开始一局」（会清理对应控制器缓存并重置进度）。
- **世界线分岔**：走错了不需要销毁后续剧情，直接从任意历史幕分岔出新世界线重新选择：

```text
主线        第1幕 ── 第2幕 ── 第3幕 ── 第4幕      ← 原样保留
                    │
世界线 2             └── 第2幕' ── 第3幕'          ← 重新做选择
```

每条世界线独立持有 `history` / `chronicle` / `worldState` 三件套，配合每幕快照（`chronicleAfter` / `worldStateAfter`）与分岔基准态（`baseState` / `baseChronicle`），切换、分岔与重生成均严格保证时间点一致。

## 架构

```text
lib/
├── core/        应用常量 · 统一错误分类（AppError）
├── models/      世界书 · 世界线 · 幕节点 · 世界状态 · 词条人物 · 存档槽 · 配置
├── data/        本地防抖存储 · 系统加密存储 · 世界书仓库
├── services/    双轨流式客户端（LlmClient）· 厂商预设（Providers）· 双轨解析（ResponseParser）
│                提示词三层内核 · 兜底与残文抢救 · 增量编年史 · 推演控制器（GenerationController）
│                分槽原子存档（SaveService）· 会话状态机（GameSession）· 世界状态 · 导出与日志
└── ui/
    ├── themes/  四套阅读皮肤与 ReadingPalette 扩展
    ├── screens/ 主壳 · 世界 / 继续 / 我的 · 高性能懒加载阅读器 · 编辑器 · 设置
    └── widgets/ 段落排版 · 章节卡片 · 流式思考面板 · 阅读弹层 / 导出与世界线树 · 自由输入栏
```

### 双轨流与解析流水线

1. **网络层物理隔离**：`LlmClient.streamChunks()` 直接把 SSE 中的 `reasoning_content` / `reasoning` / `thought` 产出为 `LlmChunk.thought`，把 `content` 产出为 `LlmChunk.content`（兼容反代内嵌 `<think>`）。
2. **控制层节流预计算**：`GenerationController` 维护独立的思考缓冲与正文缓冲，以 60ms 节流更新预览并通知局部 UI，杜绝在渲染线程反复做全量正则匹配。
3. **视图层局部刷新**：`ReaderScreen` 使用 `CustomScrollView` + `SliverList.builder` 懒加载历史幕次，流式区独立 `ListenableBuilder` 局部重绘，历史正文零重建。
4. **提示词三层与输出契约**：内核层锁定 `<date>` / `<choices>` / `<glossary>` / `<cast>` / `<state>` 空骨架契约（防止模型照抄占位词），框架层可自定义叙事风格，世界层完全由用户世界书驱动。

## 隐私

- 世界书与分槽存档仅保存在设备本地（Android 私有存储目录）
- API Key 通过系统加密存储（Android EncryptedSharedPreferences）保存，清空全部数据时同步彻底清除
- 运行日志仅驻留内存环形缓冲（上限 2000 条），默认关闭，导出前强制执行双重密钥脱敏
- 推演内容直连你自己配置的模型接口，本项目无任何中转服务器
